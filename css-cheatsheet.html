CSS Cheat Sheet

Property Description
color Sets the text color of an element. Accepts names, HEX, RGB, HSL, etc.
background-color Defines the background color behind an element’s content and padding.
font-size Controls the size of the text. Can use px, em, rem, %, etc.
font-family Specifies the typeface used for text. Often written as a list of fallback fonts.
margin Sets the outer spacing around an element, creating space between it and other elements.
padding Sets the inner spacing inside an element, between its content and its border.
border Adds a border around an element. Can define width, style, and color in one line.
width Defines how wide an element is. Can use fixed units (px) or flexible units (%).
height Defines how tall an element is. Works similarly to width.
display Controls how an element behaves in the layout (e.g., block, inline, flex, grid).
position Determines how an element is positioned on the page: static, relative, absolute, fixed, sticky.
text-align Aligns inline content (like text) inside its container: left, right, center, justify.
float Pushes an element to the left or right, allowing text to wrap around it. Mostly legacy.
overflow Controls what happens when content exceeds the element’s box: visible, hidden, scroll, auto.
z-index Sets the stacking order of positioned elements, higher values appear on top.
