JavaScript Cheat Sheet

Concept Description
let Declares a block‑scoped variable whose value can change later.
const Declares a block‑scoped constant that cannot be reassigned.
function Defines a reusable block of code that performs a task.
return Sends a value back from a function to where it was called.
if Runs code only when a condition is true.
else Runs an alternative block when the if condition is false.
for Creates a loop that repeats code a set number of times.
while Repeats code as long as a condition remains true.
console.log() Prints messages to the browser console for debugging.
document.getElementById() Selects an HTML element by its id so you can read or change it.
addEventListener() Attaches a listener that runs code when an event happens (click, input, etc.).
=== Strict comparison operator, checks if value AND type are equal.
Number() Converts a value into a number.
Array.push() Adds a new item to the end of an array.
Array.length Returns the number of items inside an array.
